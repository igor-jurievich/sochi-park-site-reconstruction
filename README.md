# Реконструкция sochipark-info.ru/index_gift2_113.html

Локальная, автономная реконструкция публичного лендинга ЖК «Сочи Парк». Основной URL, короткие совместимые маршруты, юридические страницы, медиа и весь квиз работают без обращения к исходному сайту.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000/index_gift2_113.html`.

Проверки:

```bash
npm run lint
npm run test:e2e
npm run build
```

E2E-тесты используют установленный Chrome и автоматически подключаются к уже запущенному серверу на `localhost:3000`.

## Маршруты

- `/` и `/index_gift2_113.html` — основная реконструкция.
- `/index_ctrl113.html` — совместимый короткий маршрут.
- `/kvartiry-sochi.html` — совместимый маршрут к короткой реконструкции.
- `/privacy.html` и `/policy.html` — локальные версии юридических страниц.

## Структура

- `components/SitePage.tsx` — секции лендинга, CTA и видеомодал.
- `components/QuizModal.tsx` — состояние, переходы и валидация квиза.
- `data/quiz.ts` — вопросы, варианты и messenger-конфигурация.
- `lib/submitLead.ts` — локальный адаптер отправки заявки.
- `public/` — 29 локальных ресурсов: изображения, SVG, логотипы, видео и юридический HTML.
- `tests/quiz.spec.ts` — основной, альтернативный, повторный и мобильный сценарии.
- `research/` — карта сайта, аудит UI, интеракций и контрольные скриншоты.

## Квиз и формы

Квиз воспроизводит 5 вопросов, подарок Hoff, промежуточный экран анализа, выбор WhatsApp / Telegram / Max и финальную форму. Состояние подарка хранится в `sessionStorage`, число найденных квартир выбирается в исходном диапазоне 8–15, а кнопка «Назад» повторяет пропуски промежуточных экранов оригинала.

Отправка намеренно локальная: старая CRM и аналитические скрипты не вызываются. Для подключения backend замените реализацию `submitLead()` в `lib/submitLead.ts`, сохранив существующий тип payload.
