# Формы

На основной странице отдельных форм нет. Единственная форма — финал quiz.

- Country select: `+7`, `+380`, `+375`.
- Телефон: для `+7` требуется номер формата `9XXXXXXXXX`, визуально `999 999 99 99`; для других кодов минимум 7 цифр.
- После валидного телефона раскрывается необязательное имя.
- Checkbox согласия включён по умолчанию; ссылка ведёт на локальные политики.
- Ошибки: «Введите верный номер телефона» и «Необходимо согласиться с политикой конфиденциальности».
- Кнопка: «Смотреть мою подборку»; в восстановленной версии используется безопасный local mock без старой CRM.
